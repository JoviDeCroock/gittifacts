# CI DSL (.platform/ci.ts)

`.platform/ci.ts` default-exports `async (ci) => { ... }`. The platform evaluates it in a sandbox in plan mode (no `node_modules`, git host only, 120 s) and records a static graph of steps.

- `ci.runner(opts)` starts a step from a fresh checkout.
- `step.runner(opts)` starts a step from that step's container snapshot, so it reuses the install.
- Steps you start without awaiting in between run in parallel.
- The platform adds its evidence steps after yours. Without the file, a default pipeline is detected from `package.json`.

## Runner options

| Option | Type | Meaning |
| --- | --- | --- |
| `name` | `string` | Step name: `^[A-Za-z0-9][A-Za-z0-9._-]{0,62}$`. Not `prepare`, `plan`, `finalize`, and no `:` (reserved for `evidence:*`). |
| `command` | `string` | Shell command (`sh -c`), max 8192 characters. |
| `cwd` | `string` | Working directory, relative to the repository root. |
| `env` | `Record<string, string>` | At most 32 entries, values up to 1024 characters. Keys starting with `GITTIFACTS_`, `GIT_CONFIG_`, `ARTIFACTS_` are reserved. |
| `cache` | `{ inputs: string[] }` | Up to 32 globs. When none of the matching files changed, the step is skipped and its last result and snapshot are reused. |
| `cacheScope` | `"global" \| "repo"` | `global` (share with identical inputs in any repo) or `repo`. See `StepSpec.cacheScope`. |
| `artifacts` | `{ name, paths, optional? }[]` | Build outputs to upload after success, e.g. `[{ name: "bundle", paths: ["dist"] }]`. At most 8 per step; names are unique across the pipeline. The build step's `bundle` is what a rollout deploys. |
| `instance` | `"lite" \| "standard-1" \| "standard-2" \| "standard-3" \| "standard-4"` | Container size. Default `standard-2`. Default `standard-2`. |
| `timeoutMinutes` | `number` | 1–30, default 25. |
| `config` | `{ timeout?, commandTimeoutMs?, retries?, snapshotRetentionSeconds? }` | `@cloudflare/ci` compatibility: `timeout`/`commandTimeoutMs` (ms) map to `timeoutMinutes`. |
| `secrets, cloudflareCredentials, sourceControlCredentials` | `—` | Rejected: CI steps never receive platform credentials or secrets. |

## Step environment

Each step runs in its own container as user `runner` in `/workspace`: a shallow, blobless checkout at the head commit, with no credentials. Steps never get secrets or platform tokens. The whole environment is:

- `HOME=/home/runner`, `CI=true`, `LANG=C.UTF-8`, `TERM=dumb`, then the step's own `env`;
- `GITTIFACTS=1`, `GITTIFACTS_RUN_ID`, `GITTIFACTS_STEP`, `GITTIFACTS_HEAD_SHA`;
- evidence steps only: `GITTIFACTS_BASE_SHA`;
- merge-queue batch runs only: `GITTIFACTS_TEST_TARGETS`, the affected test targets. A test command that ignores it runs everything.

## The file new projects get

```ts
// CI pipeline, generated by gittifacts conventions v1. Edit freely; edits to .platform/**
// are always Lane 2 and need a human's approval.
//
// Self-contained on purpose (no imports): the platform evaluates this file in a sandbox with a
// `ci` builder. `await ci.runner()` runs a step from a fresh checkout and resolves to the finished
// step; `step.runner()` runs a step from that step's snapshot (so it reuses the install). Steps
// started without awaiting in between run in parallel. A step is skipped, reusing its last
// result, when none of its `cache.inputs` files changed.
// The platform adds its evidence steps (red/green, coverage, public API, ...) after these.
// The `bundle` artifact of the build step is what a rollout deploys (when a deploy target is set).

type RunnerSpec = {
  name: string;
  command: string;
  cache?: { inputs: string[] };
  artifacts?: { name: string; paths: string[] }[];
};
type Step = { runner(spec: RunnerSpec): Promise<Step> };
type Ci = Step;

const INPUTS = ["src/**", "test/**", "package.json", "pnpm-lock.yaml", "tsconfig.json"];

export default async (ci: Ci) => {
  const install = await ci.runner({
    name: "install",
    command: "pnpm install --frozen-lockfile",
    cache: { inputs: ["**/package.json", "pnpm-lock.yaml", "pnpm-workspace.yaml", ".npmrc"] },
  });

  // Independent checks run in parallel, each from the install snapshot.
  await Promise.all([
    install.runner({ name: "lint", command: "pnpm run lint", cache: { inputs: INPUTS } }),
    install.runner({ name: "typecheck", command: "pnpm run typecheck", cache: { inputs: INPUTS } }),
    install.runner({ name: "test", command: "pnpm run test", cache: { inputs: INPUTS } }),
    install.runner({
      name: "build",
      command: "pnpm run build",
      cache: { inputs: INPUTS },
      artifacts: [{ name: "bundle", paths: ["dist"] }],
    }),
  ]);
};
```
