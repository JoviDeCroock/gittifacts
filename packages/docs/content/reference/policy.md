# Policy schema (.platform/policy.ts)

`.platform/policy.ts` default-exports a plain object validated against `RepoPolicy`. The platform reads it from the **base** commit of every Change, never from the Change's head, so an edit applies to Changes that start after it merges. A Change that touches `.platform/**` is always Lane 2 and needs a human's approval.
